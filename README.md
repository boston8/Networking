# Networking

My hand-made networking labs and projects completed using Cisco Packet Tracer.

This repository documents my progression from networking fundamentals to
switching, routing, network services, security, troubleshooting, and
larger network designs.

The goal of this repository is to develop practical networking skills
through configuration, testing, troubleshooting, and documentation.

## About

I am building practical networking experience alongside university studies

Most of my previous networking experience has been theoretical, so
this repository focuses on turning that knowledge into practical,
hands-on skills using Cisco Packet Tracer.

Each lab contains the topology, configuration, testing, and notes
from the exercise.
